## ✨ امکانات

### 🎯 هسته محصول
- ⏱️ **۵ بازه زمانی:** امروز، دیروز، هفته گذشته، ماه گذشته، یک سال گذشته
- 🏆 **۱۰ ایده برتر هر بازه** با رأی واقعی از ProductHunt
- 📂 **دسته‌بندی سلسله‌مراتبی:** ۲۲ دسته اصلی + ۱۵۰+ زیردسته (به سبک ProductHunt)
- 📊 **مرتب‌سازی بر اساس بیشترین رأی** در صفحات دسته‌بندی
- 🔗 **صفحه اختصاصی برای هر ایده** با جزئیات کامل

### 🤖 هوش مصنوعی
- 🇮🇷 ترجمه فارسی روان توضیحات هر ایده
- 💡 **تحلیل مشابه ایرانی:** فرصت بازار، بودجه، مخاطب، چالش‌ها، مدل درآمدی، tech stack و ضریب اطمینان
- 💬 خلاصه نظرات جامعه به فارسی
- 🖥️ اجرا روی GitHub Actions (IP آمریکا) با Groq

### 👥 کاربر و جامعه
- 🔐 ثبت‌نام / ورود با ایمیل + جلسه امن (Session)
- ⭐ **امتیازدهی ستاره‌ای ۱ تا ۵** برای هر ایده
- ❤️ لایک و 💬 کامنت برای هر ایده
- 📤 **اشتراک‌گذاری:** توییتر/X، لینکدین، تلگرام، واتساپ + کپی لینک
- 👤 **داشبورد شخصی:** پروفایل با آواتار، نام، استان، شهر و موبایل

### 🔒 محتوای قفل‌شده (Gated Content)
- توضیحات کامل، وب‌سایت رسمی، اسکرین‌شات‌ها و تحلیل مشابه ایرانی فقط بعد از ثبت‌نام رایگان

### 🖼️ صفحه محصول
- 📸 اسکرین‌شات محصول (رسانه ProductHunt یا thum.io)
- 🏅 رتبه ایده در هر بازه + 📅 تاریخ انتشار شمسی
- 👤 نام سازنده + 🔥 تعداد رأی + 🌐 وب‌سایت رسمی

### 🎨 UI/UX
- 🌓 **دارک‌مود کامل** با سوییچ ماه/خورشید
- 🚀 لوگوی موشک مینیمال (SVG)
- 🔴 نشان «آنلاین» چشمک‌زن
- 📋 دراپ‌داون دسته‌بندی‌ها در هدر
- ⏎ ورود با کلید Enter
- 📱 کاملاً واکنش‌گرا + فونت وزیرمتن

### 👑 CRM بنیان‌گذار
- 📋 لیست کاربران ثبت‌نام‌شده با **تاریخ شمسی کامل** (روز هفته، روز ماه سال، ساعت)
- 🔍 جستجو در ایمیل/نام/موبایل
- 🔐 دسترسی فقط برای ادمین

### 🌍 سئو (SEO 2026)
- 🧩 Schema.org (Organization + WebSite)
- 🗺️ `sitemap.xml` + `robots.txt`
- 🏷️ `generateMetadata` پویا برای محصول/دسته/برچسب
- 🔑 کلمات کلیدی فارسی + OpenGraph + Twitter Card

### ⚙️ زیرساخت
- 🤖 **اسکرپ خودکار روزانه ساعت ۱۷ به وقت تهران** (GitHub Actions)
- 🚀 دیپلوی خودکار روی Vercel
- 💾 دیتابیس سرورلس Neon Postgres
- 🏷️ Semantic Release خودکار

## 🚀 اجرای محلی

```bash
# 1) نصب وابستگی‌ها
bun install

# 2) تنظیم متغیرهای محیطی (.env.local)
PH_API_TOKEN=...        # توکن توسعه‌دهنده ProductHunt
GROQ_API_KEY=...        # کلید Groq
DATABASE_URL=...        # رشته اتصال Neon
ADMIN_EMAIL=...         # ایمیل بنیان‌گذار

# 3) اسکرپ داده‌ها
bun run scrape -- --no-ai

# 4) اجرای توسعه
bun run dev
