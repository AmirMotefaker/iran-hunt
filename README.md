# 🚀 ایده‌جو — IdehJo

**ایده‌ی درست، در زمان درست**

پلتفرم هوشمند ایده‌های ترند استارتاپی؛ هر روز ۱۰ ایده برتر جهانی در ۵ بازه زمانی با رتبه‌بندی واقعی، ترجمه فارسی روان، تحلیل مشابه ایرانی با هوش مصنوعی و دسته‌بندی سلسله‌مراتبی به سبک ProductHunt.

## ✨ امکانات

### 🎯 هسته محصول
- ⏱️ پنج بازه زمانی: امروز، دیروز، هفته گذشته، ماه گذشته، یک سال گذشته
- 🏆 ۱۰ ایده برتر هر بازه با رأی واقعی از ProductHunt
- 📂 دسته‌بندی سلسله‌مراتبی
- 📊 مرتب‌سازی بر اساس بیشترین رأی
- 🔗 صفحه اختصاصی برای هر ایده

### 🤖 هوش مصنوعی
- 🇮🇷 ترجمه فارسی روان توضیحات هر ایده
- 💡 تحلیل مشابه ایرانی
- 💬 خلاصه نظرات جامعه به فارسی
- 🖥️ اجرا روی GitHub Actions با Groq

### 👥 کاربر و جامعه
- 🔐 ثبت‌نام و ورود
- ⭐ امتیازدهی
- ❤️ لایک و 💬 کامنت
- 📤 اشتراک‌گذاری
- 👤 داشبورد شخصی

### ⚙️ زیرساخت
- 🤖 اسکرپ خودکار روزانه با GitHub Actions
- 🚀 دیپلوی خودکار روی Vercel
- 💾 Neon Postgres
- 🏷️ Semantic Release

## 🛠 تکنولوژی‌ها

| لایه | تکنولوژی |
|---|---|
| فریم‌ورک | Next.js 16 |
| زبان | TypeScript |
| رانتایم | Bun |
| استایل | Tailwind CSS 4 |
| دیتابیس | Neon |
| هوش مصنوعی | Groq |
| اسکرپ | ProductHunt GraphQL + Atom |
| دیپلوی | Vercel + GitHub Actions |
